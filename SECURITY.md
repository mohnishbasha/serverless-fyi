# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately. Do not open a public issue.

- Email: <mohinish@serverlessvc.com>
- GitHub: use **Report a vulnerability** under the repository's Security tab (private vulnerability reporting).

Please include the affected URL or file, steps to reproduce, and the impact. We acknowledge reports within **3 business days** and aim to fix confirmed issues within **30 days**. We will credit you if you want.

## Scope

- The static site at `https://www.serverless.fyi/` and this repository's code, workflows and infrastructure as code (`infra/`).
- The self-hosted newsletter stack at `lists.serverless.fyi`, once launched.

Out of scope: third-party platforms (GitHub, Beehiiv, AWS) and social-engineering attacks.

## Supported versions

Only the latest deployed version of the site is supported.
