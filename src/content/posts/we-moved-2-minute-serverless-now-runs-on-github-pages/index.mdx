**2 Minute Serverless now lives on GitHub Pages.** The site you're reading is a static [Astro](https://astro.build) build, generated from Markdown files in a public git repository and deployed by GitHub Actions. Beehiiv served us well. But owning the content, the URLs and the inbox matters more as the newsletter grows.

## What changed for readers?

Almost nothing you'll have to think about:

- **Same URLs.** All 23 posts kept their exact slugs. A test checks every one of the 63 legacy URLs on every deploy. Old tag links like `/t/distributed~systems` redirect to `/t/distributed-systems/`.
- **Faster pages.** Pages are plain HTML with no framework JavaScript. Lighthouse on mobile scores 100 for performance, accessibility, best practices and SEO. A post weighs about 80 KB.
- **Dark mode, search and feeds.** There's a theme toggle, full-text [search](/search/), and [RSS](/rss.xml), Atom and JSON feeds with full content.

## How does it work under the hood?

Each issue is one MDX file. Opening a pull request runs the full check suite:

- unit and end-to-end tests on four screen sizes;
- accessibility checks in light and dark mode;
- Lighthouse budgets;
- validators for structured data, feeds and the legacy URL list.

Merging the PR publishes the post in under five minutes. The migration itself was code too: a scraper read each Beehiiv post, a converter turned the HTML into clean Markdown, and every image was downloaded so nothing hotlinks Beehiiv anymore.

## What about AI agents?

They're welcome. Every post has a Markdown twin. Add `.md` to any post URL, like [/p/understanding-the-dns-header.md](/p/understanding-the-dns-header.md). The whole archive is indexed in [/llms.txt](/llms.txt), and [/api/posts.json](/api/posts.json) is a machine-readable index. ChatGPT, Claude and Perplexity can read and cite posts cleanly.
